## Objective

The objective of this experiment is to understand the basic structure of an HTML5 document and implement various HTML5 elements such as semantic tags, text formatting, lists, tables, forms, multimedia, and interactive elements to create a responsive web page.

## Software Requirements

- Visual Studio Code
- Google Chrome
- Git
- GitHub

## Procedure

1. Created the basic HTML5 page structure.
2. Added semantic elements including header, navigation, main, section, article, and footer.
3. Implemented text formatting tags and different types of lists.
4. Designed a comparison table for backend technologies.
5. Developed a registration form using various HTML5 input elements.
6. Embedded multimedia content including images, audio, and video.
7. Added interactive HTML5 elements such as details, dialog, progress, meter, and datalist.
8. Tested the webpage locally and uploaded the project to GitHub.
