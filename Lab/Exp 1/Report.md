The objective of this experiment is to understand the basic structure of an HTML5 document and implement various HTML5 elements such as semantic elements, text formatting, lists, tables, forms, multimedia, and interactive elements to create a structured, responsive, and interactive web page.

## Problem Statement

Create a web page using HTML5 elements and demonstrate the use of semantic structure, text formatting, lists, tables, forms, multimedia elements, and interactive HTML5 elements.

The webpage should demonstrate the practical use of HTML5 elements while maintaining a structured and responsive layout.
